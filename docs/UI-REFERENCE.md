# UI Reference

Property Lens uses a clean, responsive real-estate dashboard for quick comparison across Vizag, Tanuku, Palakollu and Bhimavaram.

## Design principles
- Desktop sidebar with compact navigation
- City-level summary cards
- Filter-first property discovery
- Deal labels and negotiation targets
- Responsive property cards with direct listing links
- Browser-local shortlist, visited state and personal notes
- No framework or build step
