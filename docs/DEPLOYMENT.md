# GitHub Pages Deployment

This app requires no build step. The repository includes `.github/workflows/pages.yml`.

## Enable Pages once
1. Open **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. Open **Actions** and run/re-run **Deploy static site to GitHub Pages** if needed.

Expected URL:

https://varunjakkampudi-tech.github.io/property-lens/

Every push to `main` will redeploy automatically.
